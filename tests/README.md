# Проверки MVP

Откройте **index.html** в браузере и проверьте:

1. Выберите дату **2012-12-21** при корреляции **584283**: Long Count должен быть **13.0.0.0.0**.
2. Для эпохи **0.0.0.0.0** ожидаемые опорные значения Tzolk'in и Haab' — **4 Ajaw 8 Kumk'u**.
3. Введите Long Count **13.0.0.0.0** в обратное преобразование: ожидаемая григорианская дата — **2012-12-21** при корреляции 584283.
4. Измените корреляцию на другое целое число: Long Count и календарные циклы должны пересчитаться, а выбранная григорианская дата — остаться прежней.
5. Проверьте даты на границе месяца и года, а также некорректный ввод.

Это ручной smoke-test. Автоматизированный test runner и дополнительные исторические эталоны ещё не добавлены.

# YUGATNeoTIME — Синтез времени

Исследовательский прототип для сопоставления календарных систем в общей модели времени, сохраняя их исторические правила и неопределённости.

## Что реализовано

- Григорианская дата как гражданский слой.
- Календарь Майя: Long Count, Tzolk'in и Haab'.
- Древнеегипетский гражданский календарь: 12 месяцев по 30 дней, три сезона Akhet, Peret, Shemu и 5 эпагоменальных дней.
- Настраиваемая корреляция GMT для календаря Майя (по умолчанию 584283).
- Настраиваемая математическая эпоха для египетского календаря. По умолчанию она привязана к 2026-01-01 исключительно как демонстрационная точка отсчёта, а не как историческая датировка.
- Обратное преобразование Long Count в григорианскую дату.
- Кольцевая 2D-проекция фаз календарных циклов для исследовательского сопоставления.
- Описание архитектуры проекции и ограничений: [HOLOGRAPHIC_TIME_PROJECTION.md](./docs/HOLOGRAPHIC_TIME_PROJECTION.md).
- Вычисления выполняются в браузере без сторонних библиотек.

## Запуск

Откройте index.html в браузере или включите GitHub Pages: Settings → Pages → Deploy from a branch → main → / (root).

## Египетский слой: ограничения

Древнеегипетский гражданский год состоял из 365 дней: 12 месяцев по 30 дней и пяти дополнительных дней в конце года. В отличие от календарей с високосным днём, этот год не сохранял постоянного соответствия сезонам солнечного года и постепенно смещался относительно них. Египтяне также использовали лунные календари для некоторых религиозных целей; гражданский календарь — не вся история египетского летоисчисления.

MVP не предполагает, что одна бесспорная эпоха подходит для всех исторических периодов. Пользователь задаёт расчётную эпоху, а программа вычисляет пролептическую последовательность 365-дневных лет от неё. Для реальной исторической конвертации необходимо добавить режимы по периодам, царские годы и документированные опорные даты. Подробнее: [историческая модель и источники](./docs/EGYPTIAN_CALENDAR.md).

## Метод Майя

- Внутреннее представление даты использует целочисленный Julian Day Number (JDN).
- Long Count рассчитывается как JDN минус GMT correlation.
- Tzolk'in и Haab' рассчитываются циклически относительно принятой эпохи 0.0.0.0.0 = 4 Ajaw 8 Kumk'u.
- Корреляция GMT 584283 является распространённым выбором, но остаётся параметром модели, который следует указывать явно.

## Эпистемические метки

- OBSERVED — входные данные или непосредственно проверяемый результат.
- DERIVED — результат вычисления по указанному алгоритму.
- CLAIMED — историческое или интерпретационное утверждение, требующее источника.
- NOT_TESTED — ещё не проверенная функция.
- RESIDUAL — неизвестные и ограничения модели.

Календарное совпадение само по себе не доказывает причинную связь с событиями или поведением.

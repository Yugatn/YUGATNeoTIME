# YUGATNeoTIME — приложение для macOS

**Нативное приложение для macOS 14+** на SwiftUI, часть исследовательского проекта «Синтез времени». Автор концепции: **Югатн (Yugatn)**.

## Рабочие функции MVP

- Местное время с секундами и часы восьми часовых поясов; смещения обновляются через системную базу часовых зон.
- Меню в строке состояния Mac для быстрого доступа к приложению.
- «Часы жизни» с двумя встречными процентами, прожитыми сутками и самостоятельно выбранным ориентиром от 1 до 250 лет.
- Математическое сопоставление григорианской и юлианской календарных дат.
- Автономная работа ядра без интернета.
- Добровольное локальное сохранение даты рождения в настройках приложения с явной кнопкой удаления.

**Важно:** временной ориентир не означает прогноз смерти и не является медицинским заключением. Другие исторические разделы веб-атласа доступны отдельно по ссылке и пока не перенесены в нативный интерфейс.

## Получить приложение

После успешной сборки откройте GitHub **Actions → macOS native app → последний успешный запуск → Artifacts → YUGATNeoTIME-macOS**. В архиве находится файл `YUGATNeoTIME-macOS.zip` с приложением `.app`. У артефактов GitHub ограниченный срок хранения; для загрузки может потребоваться войти в аккаунт.

Сейчас используется **ad-hoc code signing**, а не Apple Developer ID notarization. При скачивании из интернета macOS может запросить отдельное подтверждение запуска неизвестного разработчика.

## Собрать на своём Mac

Требования: **macOS 14+**, Xcode и Command Line Tools, Swift 5.9+.

```bash
git clone https://github.com/Yugatn/YUGATNeoTIME.git
cd YUGATNeoTIME/macos
swift test
bash scripts/build-app.sh
open dist/YUGATNeoTIME.app
```

При работе с открытым PR до слияния переключите `git checkout feat/native-macos-time-app-2026-11` перед `cd macos`.

Результат: `macos/dist/YUGATNeoTIME.app` и `macos/dist/YUGATNeoTIME-macOS.zip`. Для разработки в Xcode: `open Package.swift`.

## Проверки и границы

В `TimeCore` имеются unit-тесты: взаимодополняемость процентов, недопустимые значения, переход через ориентир, 29 февраля, Julian/Gregorian. Core может проверяться на Linux, а сам SwiftUI-интерфейс собирается только на macOS. Успешная проверка Core не подтверждает готовность нативной сборки; статус GitHub Actions необходимо проверить отдельно.

Дата рождения и ориентир сохраняются в `UserDefaults` на устройстве. Телеметрии и серверного аккаунта в нативном MVP нет. Ссылка на веб-атлас открывается во внешнем браузере.
